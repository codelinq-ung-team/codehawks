zxing.dll is ZXing.Net 0.16.10 (the netstandard2.0 build from the NuGet package
https://www.nuget.org/packages/ZXing.Net/0.16.10), unmodified. It reads the QR code that pairs
the headset with a browser (Assets/Scripts/Scanner.cs).
